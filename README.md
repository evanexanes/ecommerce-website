# E-commerce store (OneStopShop)

A WooCommerce store with 30 products, 44 variations and Elementor theme-builder templates. Brand and product names are sample data; nothing is for sale. A self-initiated WordPress practice build by Evan Exanes.

- **Live demo:** https://evanexanes.github.io/ecommerce-website/
- **Case study:** https://evanexanes.github.io/04-case-study-ecommerce.html
- **Stack:** WordPress · WooCommerce · Elementor (Pro Elements) · Hello Elementor

## What this repository is

A static copy of the WordPress site, exported with Simply Static so it can run on GitHub Pages.
It is generated HTML, CSS and JavaScript, not the WordPress source: there is no PHP, database or
`wp-config.php` here.

GitHub Pages cannot run PHP, so anything that needs the WordPress server does not work in this copy.
The support form sends through Web3Forms. Cart, checkout, accounts, product filter and search need WordPress and say so when used.
